# Security

Letterlane is an early personal-use prototype. Do not publish a running instance to the internet. Keep its configuration and local data private. GitHub source visibility and running-service visibility are separate.

If you find a vulnerability, do not include Gmail messages, tokens, OAuth client secrets, private calendar URLs, or personal data in a public issue. For a public repository, use GitHub's private vulnerability reporting when available; otherwise contact the maintainer privately before sharing details.

Review the security design and limitations in README before connecting a real account. Keep macOS, Node, Tailscale, and your browser updated. No claim of an independent security audit is made.
